# 二秒カメラ（仮）企画書

## 1. 企画概要

ダンスやスポーツなど、何かに夢中になっている人が、撮影を誰かに頼まなくても、自分が残したい瞬間を写真にできるカメラシステムを開発する。

カメラ映像から人物の姿勢をリアルタイムに解析し、身体の動きが一定時間落ち着いたことを検知すると、そのタイミングの映像から静止画を切り出して保存する。最初の目標は「ピタッと止まったときに撮る」こと。

動画を作品として保存するのではなく、解析に必要な間だけ映像を扱い、写真だけを残す方式を基本とする。

## 2. 解決したいこと・想定利用者

撮影を人に頼むと、撮影者が撮りやすい場所やタイミングに偏り、自分が残したい瞬間が撮れないことがある。セルフタイマーも、カメラを置いてから時間内にポーズを取る必要があり、踊りの途中の自然な瞬間には向かない。

主な利用場面：
- 民謡、安来節、日本舞踊、ダンスの練習・発表
- DJ、パフォーマー、スポーツなど、動きのある活動
- 一人で練習しているとき、撮影を頼める人がいないとき
- 自分の好きな瞬間を自分の意図に近い形で残したいとき

## 3. 基本コンセプト

**動きを止めた瞬間を、カメラが見つけて撮影する。**

単に決めポーズを撮るだけでなく、踊りやパフォーマンスの流れの中で、本人が自然に動きを止めた瞬間を写真として残す。

## 4. 初期POCの仕様

- 対象端末：iPad mini（まずはSafari）
- 配布方法：GitHub Pagesで公開するWebアプリ
- カメラ：端末内蔵カメラ
- 映像取得：getUserMedia（MediaDevices API）
- 姿勢推定：MediaPipe Pose Landmarker
- 静止判定：姿勢ランドマークの位置変化量を連続フレーム間で比較
- 静止時間：初期値2秒。1〜3秒程度で調整できるようにする
- 静止画抽出：video要素とCanvas API
- 保存：まずは画面上に写真を表示。端末への保存方法は別途検証

## 5. 撮影の流れ

1. HTTPSでWebアプリを開き、利用者がカメラ起動を許可する。
2. カメラ映像をブラウザ内で一時取得する。
3. MediaPipeで人物の姿勢ランドマークを検出する。
4. ランドマークの位置変化が小さい状態が設定時間続いたら「静止」と判定する。
5. 判定したタイミングのフレームをCanvasで静止画にする。
6. 静止画を画面のギャラリーに追加する。
7. 次の動きを待ち、再び静止したら次の写真を撮る。

映像はサーバーへ送信せず、動画ファイルとして保存しない。ブラウザ内で解析し、写真だけを残すことを基本方針とする。

## 6. 静止判定について

人の身体は完全には静止しないため、ランドマークの移動量に許容範囲を設ける。カメラの揺れ、衣服や手先の小さな揺れ、姿勢推定の誤差もあるため、判定値は実際の踊りで調整する必要がある。

初期POCでは、以下を確認する。
- 1秒・2秒・3秒で撮影結果がどう変わるか
- 決めポーズと、踊りの途中の一時的な動きの谷間を区別できるか
- 全身が画面に入っていない場合や、人物を検出できない場合の挙動
- 感度を変えたときの撮りすぎ・撮り逃し
- 同じポーズを連続撮影しない制御

まずは「一定時間、姿勢の変化が小さければ撮影する」という単純な基準で動作を確かめ、その後に踊りの種類に合わせて改善する。

## 7. 重要な検討事項

### 撮影フレームの選び方
初期版では静止判定が成立した時点のフレームを撮影する。次の段階で、静止していた時間帯の複数フレームから、よりよい姿勢・表情の写真を選ぶ方式と比較する。

### 撮りすぎの防止
同じ姿勢が続いている間は一度だけ撮影し、いったん動き出してから次の静止を検出する。必要に応じて撮影間隔や再撮影条件を追加する。

### 写真の保存
まずは撮影結果を画面上で確認できるようにする。iPadの写真アプリへの保存は、Safariの仕様を実機で確認してから実装する。

### 端末負荷
姿勢推定を続けた場合の発熱、バッテリー、処理速度をiPad mini実機で確認する。

## 9. 初期POCで確認すること

最初に確認するのは、機能をたくさん増やすことではなく、**踊っている人がピタッと止まったときに、意図したタイミングで写真が撮れるか**である。

実際の踊りで試し、撮影された写真を見ながら、静止時間・感度・撮影タイミングを調整する。

## 10. 企画の本質

撮影する人がいなくても、自分の好きなことに夢中になれる。そして、その時間の中にある、自分では気づかなかった素敵な瞬間をカメラが見つけて残してくれる。

自分が撮ってほしい瞬間を、自分の代わりにカメラが見つけてくれる。そんな新しい自動撮影の仕組みを実現する。

---

## 技術上の注意

- ブラウザでカメラを使うにはHTTPS環境とユーザーのカメラ許可が必要。
- iPad miniの機種・OS・Safariのバージョンによって性能や対応状況が異なる。
- MediaPipeのモデル読み込みにはインターネット接続が必要。
- 現段階は実験用POCであり、撮影精度や長時間の安定動作を保証するものではない。
- カメラ映像はブラウザ内で処理する設計だが、実機で通信・保存動作を確認する。
